**Recursion**-: It is a problem-solving technique where a function calls itself to solve smaller instance of the same problem until a base case is reached 
- base case -stops the recursion
- Recursive case - The function calls itself on a smaller input 

A **recurrence relation** is an equation that defines a function **in terms of its value on smaller inputs**.

**Master’s Theorem** is one of the **best and fastest methods** to find the **time complexity of divide-and-conquer recursive algorithms**

**Recursion Tree** :- Recursion tree is another method for solving the recurrence relations it is a tree where each node represents the cost of a certain recursive problem sum up the values in each node to get the cost of the entire algorithm
